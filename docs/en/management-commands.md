# ⚙️ Management Commands & Catalog Scripts Reference (English)

Custom Django management commands reside in `tracker/management/commands/`. They focus on downloading, normalizing, and verifying offline multimedia assets (sprites, animations, icons, and audio cries).

Game catalog compilation is handled by edition-specific builder scripts in `tracker/scripts/` following the guidelines in `guides/especificacion-nuevo-juego.md`.

---

## 1. Multimedia Asset Sync Commands (`manage.py`)

Commands are run using Django's standard CLI: `python manage.py <command> [options]`.

| Command | Purpose | Target Directory |
| :--- | :--- | :--- |
| `sync_pokemon_cries` | Downloads and organizes 8-bit vintage and modern audio cries in OGG format. | `media/pokemon/cries/` |
| `sync_pokemon_icons` | Synchronizes standard PC/menu icons for all Pokédex species. | `media/pokemon/icons/` |
| `sync_classic_icons` | Downloads retro pixel-art menu icons matching cartridge style. | `media/pokemon/icons/classic/` |
| `sync_items` | Downloads official inventory icons for evolution stones and items. | `media/items/` |
| `sync_unown_sprites` | Downloads all 26-28 alphabetical forms of Unown (normal and shiny). | `media/pokemon/sprites/unown/` |
| `sync_crystal_sprites` | Downloads static battle sprites from Pokémon Crystal. | `media/pokemon/sprites/crystal/` |
| `sync_crystal_animated_sprites` | Downloads entry animation GIFs from Pokémon Crystal. | `media/pokemon/sprites/crystal_animated/` |
| `sync_emerald_animated_sprites` | Downloads animated battle sprites exclusive to Pokémon Emerald. | `media/pokemon/sprites/emerald_animated/` |
| `sync_gold_shiny_sprites` | Synchronizes shiny variant sprites for Pokémon Gold. | `media/pokemon/sprites/gold_shiny/` |
| `sync_silver_sprites` | Synchronizes cartridge sprites for Pokémon Silver. | `media/pokemon/sprites/silver/` |
| `normalize_gen1_sprites` | Normalizes aspect ratio and palette for Generation 1 sprites. | `media/pokemon/sprites/` |
| `sync_wikidex_flavor_texts` | Scrapes and updates official Spanish descriptions from WikiDex. | `tracker/data/catalogs/` |

## 2. Operational CLI Examples

### Synchronizing Audio Cries
Download both chiptune and orchestrated cries:
```bash
python manage.py sync_pokemon_cries
```

### Synchronizing Crystal Battle Animations
Download animated GIFs for the retro modal:
```bash
python manage.py sync_crystal_animated_sprites
```

### Synchronizing Unown Form Glyphs
Download all glyphs for the Ruins of Alph tracking:
```bash
python manage.py sync_unown_sprites
```

## 3. Game Catalog Compilation Pipeline

Game catalogs are generated by dedicated scripts under `tracker/scripts/`:

* `tracker/scripts/build_ruby_catalog.py`
* `tracker/scripts/build_sapphire_catalog.py`
* `tracker/scripts/build_emerald_catalog.py`
* `tracker/scripts/build_firered_catalog.py`
* `tracker/scripts/build_leafgreen_catalog.py`
* `tracker/scripts/build_diamond_catalog.py`

### Protocol for Adding a New Game:
1. The script specifies species present with canonical regional and national numbering.
2. Official Spanish location names and encounter methods are mapped without raw English slugs.
3. Historical generation-accurate typings are enforced (e.g. pure Electric Magnemite in Gen 1).
4. Data is exported as an immutable JSON file to `tracker/data/catalogs/<game_slug>.json`.
5. The catalog is committed to Git and immediately served by `catalog_service.py` with 0 ms SQL overhead.

> [!TIP]
> For the comprehensive technical specification on integrating new games from Gen 1 to Gen 9 and Legends, see [guides/especificacion-nuevo-juego.md](../../guides/especificacion-nuevo-juego.md).
